# 🍅 Focus Lab — 研究生專注與進度追蹤站

結合「番茄鐘」、「任務管理」、「每日心得」與「進度報告」的單頁 Web App。
本作品以 Vibe Coding 方式完成：先與 AI 討論出規格書，再請 AI 實作，經過多輪實際操作與修改後定稿。

🔗 **網站連結：** https://chiau14.github.io/focus-lab/

---

## 一、規格書

### 1. 動機與目標
研究生同時要處理實驗、論文、修課等事情，常常忙了一整週卻說不清楚做了什麼，meeting 前還要回想進度。
Focus Lab 把「專注計時」和「任務進度追蹤」放在同一頁：專注時知道自己在做哪件事，完成任務時順手記下研究結論，每天寫心得，需要報告時一鍵產生進度報告。

### 2. 目標使用者
需要管理多項研究與課業任務、定期向指導教授報告進度的研究生。

### 3. 功能需求

**A. 番茄鐘**
- 預設專注 25 分鐘、短休息 5 分鐘，每 4 個番茄長休息 15 分鐘，時間可在設定中調整
- 開始／暫停／繼續、重設、跳過；可點「專注／短休息／長休息」直接切換
- 圓形進度環＋大字倒數；專注為紅色系、休息為綠色系
- 時間到播放提示音並自動切換到下一階段
- 可選擇「目前專注任務」，完成番茄後自動記到該任務上
- 空白鍵可開始／暫停；計時中瀏覽器分頁標題會顯示倒數

**B. 任務管理**
- 新增任務：名稱、分類、截止日、預估番茄數
- 分類：研究／論文／實驗／課程／其他／每日任務，各有顏色標籤
- 截止日可勾選「無」；未選日期也未勾「無」時會提醒
- 任務以長方形卡片呈現，左側「三條線」把手可拖曳排序（滑鼠、觸控皆可）
- 新增時預設依截止日排入；提供「依截止日重新排序」按鈕
- 勾選完成後，任務移到清單最底部，並展開「研究結論／備註」欄位（可隨時修改）
- 截止提醒：已過期顯示紅色、3 天內到期顯示黃色
- 篩選：狀態（全部／未完成／已完成）、分類
- 可編輯、刪除任務

**C. 每日任務**
- 「每日任務」為其中一個分類，不需要截止日
- 每天 0 點自動恢復成未完成，排在未完成任務的最下面；完成後同樣移到最底部
- 卡片顯示「🔁 每天重複」、今日番茄數與「🔥 連續 N 天」打卡紀錄
- 完成後可寫「今日紀錄」，每天的紀錄分開保存

**D. 進度統計**
- 總完成率進度條
- 每日專注目標（預設 8 個番茄），達成時顯示彩帶慶祝動畫
- 本週完成任務數、番茄數、專注時間
- 本週各分類專注時間長條圖

**E. 進度報告**
- 按「產生進度報告」開啟視窗
- 以一頁一個月的月曆選擇日期範圍（點開始日、再點結束日），並有本週／上週／最近 7 天／本月快捷鍵
- 勾選要包含的分類，只有勾選的分類會出現在報告中
- 「文字紀錄」欄位：自行輸入的內容附在報告最後
- 報告內容：概況、完成項目（附備註）、目前進行中、每日任務打卡（附每日紀錄）、即將到期、文字紀錄
- 即時預覽、一鍵複製

**F. 日期檢視（回顧某一天）**
- 頁面最上方顯示今日日期，點擊後跳出月曆（有紀錄的日子標紅點，未來日期不可選）
- 選擇某一天後，整個頁面切換成那一天的樣子：
  - 任務清單：那天存在的任務，標示「當天完成（時間）」或「當天未完成」，並顯示當時的備註
  - 當日時間軸（取代番茄鐘位置）：依時間列出每個番茄、完成的任務與打卡
  - 當日統計：當天完成率、番茄數、專注時間、各分類時間
  - 每日心得：可查看或補寫那天的心得
- 上方提示列可一鍵「回到今天」

**G. 每日心得與提醒**
- 進度統計下方有「每日心得」框，自動儲存，提供「插入範本」（今天完成／遇到的問題／學到的東西／明天要做）
- 每天 22:00 跳出提醒詢問是否寫心得：現在寫／30 分鐘後再提醒／今天先不要；當天已寫則不提醒
- 提醒時間與開關可在設定中調整

**H. 每日一句**
- 標題下方每天自動顯示一句勉勵或幽默的話（內建 35 句，依日期輪替）
- 可點擊編輯成自己的話（只影響當天），或按 🎲 隨機換一句

**I. 外觀與資料儲存**
- 預設淺色清爽風，可切換深色模式
- 所有資料（任務、排序、備註、番茄紀錄、心得、設定）存在瀏覽器 localStorage，重新整理不會消失
- 設定中可「清除所有資料」（需按兩次確認）

### 4. 畫面配置
```
┌───────────────────────────────────────────────────┐
│ 🍅 Focus Lab          [18 2026年10月▾]  🌙 深色 ⚙ 設定 │
│ 每天一句勉勵或幽默的話 🎲✎                              │
├─────────────────────────┬─────────────────────────┤
│                         │ 番茄鐘                   │
│ 任務清單                 │ （查看過去日期時為當日時間軸）│
│ ・新增表單               ├─────────────────────────┤
│ ・狀態／分類篩選          │ 進度統計＋產生進度報告     │
│ ・任務卡片（可拖曳）       ├─────────────────────────┤
│                         │ 📝 每日心得               │
└─────────────────────────┴─────────────────────────┘
```
手機版改為上下排列：番茄鐘 → 任務清單 → 進度統計 → 每日心得。

### 5. 操作流程
1. 新增本週任務（例如「跑 baseline 實驗」，分類實驗，週五截止，預估 4 個番茄）與每日任務
2. 拖曳卡片調整優先順序，選擇一個任務按開始計時
3. 番茄完成後自動記錄並進入休息，今日目標進度增加
4. 任務完成後勾選，寫下實驗結論
5. 晚上 10 點收到提醒，寫下今天的心得
6. 需要報告時，選日期範圍與分類，加上文字紀錄，複製報告
7. 想回顧某一天時，點上方日期查看當天的任務、時間軸與心得

### 6. 資料結構（localStorage）
- **任務**：id、名稱、分類、截止日、預估番茄數、已完成番茄數、是否完成、備註、建立時間、完成時間；每日任務另有每日打卡紀錄（日期、時間、當天紀錄）
- **番茄紀錄**：完成時間、分鐘數、對應任務、分類
- **每日心得**：日期 → 內容
- **每日一句**：日期 → 自訂內容
- **設定**：番茄時間、每日目標、提醒時間與開關、深淺色模式、報告選項

### 7. 技術限制
- 單一 `index.html`，HTML、CSS、JavaScript 寫在同一檔案
- 純前端、不需後端或登入，部署於 GitHub Pages
- 支援電腦與手機瀏覽器（RWD）
- 提醒功能需要網頁開著才會跳出

### 8. 驗收標準
- [x] 番茄鐘可開始、暫停、重設、跳過，時間到自動切換並發出提示音
- [x] 完成番茄後，所選任務的番茄數與今日目標會增加
- [x] 可新增（含無截止日）、編輯、刪除、勾選任務，完成後移到最底部並可寫備註
- [x] 可拖曳排序，也能一鍵依截止日重新排序
- [x] 每日任務每天 0 點重置並排在未完成任務下方
- [x] 篩選、截止日顏色提示正常
- [x] 統計、長條圖即時更新，達成每日目標有慶祝動畫
- [x] 進度報告可用月曆選範圍、勾選分類、附文字紀錄並複製
- [x] 點日期可切換到過去某一天，正確顯示當天任務狀態、時間軸與統計
- [x] 每日心得自動儲存，22:00 跳出提醒
- [x] 每日一句每天更換，可編輯與隨機換句
- [x] 深色模式可切換；重新整理後所有資料保留
